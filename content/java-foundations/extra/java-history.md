# Evolution of Java: JDK 1.0 to Modern LTS

From Oak to modern release cadences: 25+ years of bytecode and JVM innovations.

Java began at Sun Microsystems under James Gosling. With the transition to 6-month release cadences and long-term support (LTS) releases (Java 8, 11, 17, 21), Java maintains backwards compatibility while adopting pattern matching, records, and modern garbage collectors (ZGC, Shenandoah).
