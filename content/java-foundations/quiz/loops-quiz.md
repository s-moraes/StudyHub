## Q1
Which loop guarantees that the body executes at least once?

### Option A [CORRECT]
do-while loop

### Option B
while loop

### Option C
for loop

### Option D
enhanced for-each loop

### Explanation
The do-while loop evaluates its termination condition at the bottom of the loop body.
===
## Q2
What does continue statement do inside an inner loop?

### Option A [CORRECT]
Skips the rest of the current iteration and jumps to the next iteration of that loop.

### Option B
Immediately exits all enclosing loops.

### Option C
Pauses thread execution.

### Option D
Restarts the outer loop from index 0.

### Explanation
An unlabeled continue jumps directly to the update expression of the immediately enclosing loop.
