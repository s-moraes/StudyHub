# Working with Arrays

Arrays in Java are homogeneous, fixed-size objects that hold elements of a specific type.

## Array Declaration and Initialization
```java
int[] numbers = new int[]{1, 2, 3, 4, 5};
String[] names = new String[3]; // elements default to null
```

Arrays have a fixed `length` property and elements are indexed starting from 0 to `length - 1`.
