# CAP & PACELC Theorems

Eric Brewer's CAP Theorem states that in the event of a network partition, a distributed system must choose between Consistency and Availability.

## PACELC Extension
Daniel Abadi extended CAP: If there is a Partition (P), how does your system trade Consistency (C) vs Availability (A); Else (E), how does it trade Latency (L) vs Consistency (C)?
